What changed

  • Four tools only, each a big button with a name: Crayon, Paint, Fill, Eraser. The marker is gone (too close to the crayon).
  • No size buttons. Each tool already has a good size for small fingers.
  • No "stay inside the lines" switch. It's always on, so colour never spills into the next part. One less thing to understand.
  • 12 bigger colours in two neat rows. The tools don't change colour any more, so the screen stays calm.
  • Cleaner picture: thicker, smoother lines, and a sun and a hill to colour too.

After HANG IT

  • Binhi shows the framed picture: "Ang ganda!" and +2 leaves (only the first time for each plant).
  • SEE IT IN MY GARDEN opens the garden. The picture drops onto the bahay kubo wall with a little swing and glows for a moment.
  • Tap the bahay kubo to see the gallery wall with all your pictures.

The tools

  • Crayon: waxy and a bit grainy.
  • Paint: soft and see-through. Go over it again to make it darker.
  • Fill: one tap colours a whole part.
  • Eraser, plus Undo at the top right.
